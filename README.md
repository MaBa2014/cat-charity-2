# QRKot — благотворительный фонд поддержки котиков 🐈

**QRKot** — учебный REST API благотворительного фонда, который собирает пожертвования на помощь кошкам. Фонд открывает целевые проекты: покупку корма, оплату лечения, обустройство приютов и другие инициативы. Пользователи могут поддержать фонд пожертвованием, а система самостоятельно распределит поступившие средства между актуальными проектами.

Главная особенность QRKot — **пожертвования не привязаны к конкретному проекту**. Человек помогает фонду в целом, а приложение определяет, какой сбор нуждается в финансировании в первую очередь.

## Задачи приложения

Сервис решает три основные задачи:

1. **Управление благотворительными проектами.** Фонд создаёт целевые сборы, указывает их назначение и необходимую сумму, отслеживает поступления и завершает сбор после достижения цели.
2. **Учёт пожертвований.** Зарегистрированные пользователи вносят произвольные положительные суммы и при желании оставляют комментарий. История каждого пользователя сохраняется.
3. **Автоматическое распределение денег.** Система инвестирует поступившие средства в открытые проекты без ручного выбора получателя и сохраняет остатки, если действующих сборов нет.

## Как распределяются пожертвования

Средства направляются в проекты по принципу **FIFO (first in, first out)**: в первую очередь финансируется самый ранний из незакрытых проектов. Когда его цель достигнута, оставшаяся часть пожертвования переходит к следующему проекту.

Например, фонд открыл два сбора:

| Проект | Целевая сумма |
| --- | ---: |
| Лечение котёнка | 5 000 ₽ |
| Корм для приюта | 3 000 ₽ |

Пользователь перечисляет **6 500 ₽**. Приложение автоматически распределит **5 000 ₽** на лечение котёнка и **1 500 ₽** на корм. Первый проект закроется, а второму останется собрать ещё **1 500 ₽**.

Если пожертвование поступило, когда открытых проектов нет, деньги останутся нераспределёнными. Как только появится новый проект, свободные суммы будут автоматически направлены на его финансирование. Аналогично, если пожертвование превышает потребности всех открытых проектов, неиспользованный остаток сохраняется до следующего сбора.

При достижении полной суммы проекта или полном распределении пожертвования система отмечает соответствующую запись как завершённую и фиксирует дату завершения. Создание новой записи и распределение средств выполняются **в одной транзакции базы данных**.

## Возможности и права доступа

В приложении предусмотрены две роли:

| Возможность | Пользователь | Суперпользователь |
| --- | :---: | :---: |
| Просматривать список благотворительных проектов | ✓ | ✓ |
| Регистрироваться и входить в систему | ✓ | ✓ |
| Делать пожертвования | ✓ | ✓ |
| Просматривать историю своих пожертвований | ✓ | ✓ |
| Просматривать все пожертвования и их распределение | — | ✓ |
| Создавать благотворительные проекты | — | ✓ |
| Редактировать и удалять допустимые проекты | — | ✓ |

Для сохранения достоверности учёта действуют ограничения:

- Названия проектов уникальны, а суммы сборов и пожертвований должны быть положительными.
- Закрытый проект нельзя редактировать.
- Нельзя уменьшить целевую сумму ниже уже полученных средств.
- Нельзя удалить проект, в который уже поступили деньги.
- Пожертвования не редактируются и не удаляются через API.

## Данные, с которыми работает сервис

**CharityProject** — целевой благотворительный проект. Содержит название, описание, необходимую сумму, уже собранные средства, статус завершения и даты создания и закрытия.

**Donation** — пожертвование пользователя. Хранит сумму, необязательный комментарий, уже распределённую часть средств, статус, даты поступления и полного распределения, а также связь с пользователем.

**User** — учётная запись для авторизации и разграничения доступа к операциям API.

Для моделей проектов и пожертвований используется общий абстрактный класс с полями, относящимися к финансированию и датам.

## Технологии и устройство проекта

QRKot разработан на **Python и FastAPI**. Для проверки входных данных и формирования ответов используются **Pydantic-схемы**, для работы с базой данных — асинхронный **SQLAlchemy** и **SQLite** через `aiosqlite`. Миграции структуры базы выполняются с помощью **Alembic**, а регистрацию и JWT-аутентификацию обеспечивает **FastAPI Users**.

Код разделён по ответственности:

- `app/api/endpoints/` — HTTP-эндпоинты проектов и пожертвований;
- `app/models/` — ORM-модели;
- `app/schemas/` — схемы запросов и ответов;
- `app/services/investment.py` — алгоритм распределения пожертвований;
- `app/core/` — настройки, база данных и авторизация;
- `app/main.py` — создание и конфигурация приложения FastAPI;
- `alembic/` — миграции базы данных.

API предоставляет маршруты для работы с проектами (`/charity_project/`), пожертвованиями (`/donation/`), регистрации и входа (`/auth/`) и профилем пользователя (`/users/`). Интерактивная документация создаётся автоматически средствами FastAPI и доступна в Swagger UI по адресу `/docs` при работающем сервере.

## Назначение проекта

QRKot демонстрирует реализацию серверной части благотворительного сервиса: от авторизации и разграничения ролей до транзакционной бизнес-логики учёта и распределения средств. Это **учебное API**, а не платёжная платформа: оно фиксирует пожертвования в базе данных, но не принимает реальные банковские платежи.
